快捷键


语音输入
单击开始录音，再单击结束

语音修订
先选中文本，再按此键口述修改意见。「主快捷键 + 某键」表示按住主快捷键再按该键

结束修订
说完修改意见后按此键；与语音输入键相同时单击即可结束

取消
录音或识别过程中按此键放弃本次任务；平时不会拦截这个键

LLM 润色与修订


自动润色
转写后用 LLM 去除语气词、连接断句，多个要点自动编号

翻译成
说完后用 LLM 翻译成所选语言再输入，短句也会翻译；需要填写下面的 API

API 地址
任意 OpenAI 格式接口，润色和语音修订都会用到

API Key
服务端不需要时留空

模型名
例如 gpt-4o-mini

关闭思考
通过 API 参数让推理模型跳过思考过程，明显降低延迟；不支持的服务会自动忽略

润色最短录音时长
短于此时长的录音不润色，直接输出转写结果；润色主要用来整理大段口述

润色最少字数
更短的转写结果直接输出，不调用 LLM

按上下文插入
光标前后已有文字时，用 LLM 把口述内容自然接进光标处；前后原文不会被改动

插入最短录音时长
更短的录音直接插入转写结果，不调用 LLM，速度更快

插入最少字数
更短的转写结果直接插入，不调用 LLM

提示词

发送给 LLM 的指令，可按需修改；花括号里的占位符会被替换成实际内容


润色提示词
{text} 会被替换为转写结果

修订提示词
{original} 为选中的原文，{instruction} 为口述的修改意见

插入提示词
光标前后已有文字时使用：{before}、{after} 为光标前后的文字，{text} 为转写结果
